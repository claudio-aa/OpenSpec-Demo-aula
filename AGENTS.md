# Workshop OpenSpec e ORCA

Este repositório ensina Análise de Sistemas em pt-PT. O workshop dura 60 minutos: 30 de introdução e 30 de prática guiada.

- Ler primeiro README.md e a tarefa indicada. Consultar apenas os ficheiros necessários.
- Distinguir factos do enunciado, propostas e decisões humanas. Nunca resolver silenciosamente uma ambiguidade de negócio.
- Trabalhar uma tarefa pequena de cada vez. Identificar ficheiros permitidos e critério de conclusão antes de editar.
- Manter specs, código e testes coerentes. Uma validação OpenSpec verifica a estrutura documental, não prova o comportamento do programa.
- Usar exclusivamente serviços locais ou gratuitos sem cartão nem subscrição paga. Nunca ativar billing, trials pagos ou fallback pago.
- Agentes em paralelo devem ter ficheiros diferentes. O revisor não altera o código que está a avaliar.
- O simulador não controla cancelas nem processa pagamentos reais.
- Executar npm test e npm run build para alterações funcionais. Registar o resultado real, incluindo falhas.
- Deixar um HANDOFF.md curto com estado, evidência e próxima tarefa. Não usar o histórico do chat como única memória.
