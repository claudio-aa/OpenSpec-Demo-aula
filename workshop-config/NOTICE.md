# Template do modelo revisor

O bloco `TEMPLATE` de `Modelfile.reviewer` deriva do template público de Qwen 3 4B distribuído pelo registo oficial Ollama. A adaptação fecha explicitamente o prefixo de thinking para os pedidos curtos do workshop. Os pesos não são redistribuídos neste repositório.
